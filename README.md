# AI Finder

دليل عربي/إنجليزي لاكتشاف أدوات الذكاء الاصطناعي، مع واجهات أولية لمساعد AI ومجتمع المستخدمين.

## الموجود حالياً
- واجهة متجاوبة بالعربية والإنجليزية.
- دليل أدوات مصنف إلى نصوص وصور وفيديو وصوت.
- بحث وفلترة وروابط مباشرة للأدوات.
- واجهة محادثة مساعد AI مع اختيار مزود وإرفاق صورة (واجهة فقط).
- واجهة أولية للمجتمع وتسجيل الدخول (واجهة فقط).

## تشغيل الموقع عبر GitHub Pages
1. افتح Settings ثم Pages.
2. اختر Deploy from a branch.
3. اختر الفرع main والمجلد /(root) ثم Save.
4. انتظر اكتمال النشر، وسيظهر رابط الموقع في صفحة Pages.

## ما يلزم قبل تفعيل المحادثات الحقيقية؟
GitHub Pages يستضيف ملفات الواجهة الثابتة فقط. لا تضع مفاتيح API في index.html أو JavaScript العام.

البنية المقترحة:
- Frontend: الواجهة الحالية، ويمكن تطويرها لاحقاً إلى Next.js + TypeScript.
- Backend: FastAPI لتوجيه طلبات النصوص والصور، وإدارة الجلسات والصلاحيات.
- Database/Auth: Supabase أو خدمة مكافئة لتسجيل الحسابات، ملفات المستخدمين، المحادثات والرسائل.
- AI providers: طبقة موحدة لمزودي النصوص وتحليل الصور وتوليد الصور. تحفظ المفاتيح في متغيرات بيئة الخادم فقط.
- Realtime: خدمة آمنة للرسائل الخاصة والإشعارات، مع قواعد تمنع قراءة المستخدم إلا لمحادثاته.

## متطلبات الإطلاق الآمن
- مصادقة حقيقية وتأكيد البريد واستعادة كلمة المرور.
- صلاحيات وصول على مستوى الصفوف للمحادثات والملفات.
- تحديد معدل الطلبات وحصص الاستخدام وتسجيل الأخطاء.
- الإبلاغ والحظر ومكافحة الرسائل المزعجة للمجتمع.
- سياسة خصوصية وشروط استخدام وحذف الحساب والبيانات.
- التحقق من الأسعار والحصص المجانية وشروط كل مزود قبل عرضها للمستخدمين.

**تنبيه:** لا توجد حالياً معالجة فعلية لطلبات AI أو تخزين لحسابات ورسائل المستخدمين. هذه نسخة واجهة أولية قابلة للتطوير وليست خدمة محادثة منشورة بعد.
